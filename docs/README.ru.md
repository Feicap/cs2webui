# CS2 WebUI

[English version](../README.md)

CS2 WebUI - Linux-панель для установки, настройки и управления несколькими
изолированными серверами Counter-Strike 2. Панель работает независимо от
игровых серверов и остается доступной, когда инстанс остановлен, обновляется
или восстанавливается.

Проект находится в активной разработке. В репозитории уже есть функциональная
Linux-first реализация. Перед production-использованием ее необходимо
проверить на реальном Linux/Bazzite-хосте и живом сервере CS2.

## Быстрая Установка

Перед запуском на Linux или Bazzite просмотрите bootstrap-скрипт:

```bash
curl -fsSL https://raw.githubusercontent.com/feicap/cs2webui/main/cs2webui.sh \
  -o cs2webui.sh
less cs2webui.sh
sudo bash cs2webui.sh
```

Продолжите настройку в браузере по временному URL из вывода скрипта.
Требования к хосту, проверка установки и варианты удаления описаны в
[руководстве для Linux](DEPLOYMENT.ru.md).

## Как Будет Использоваться Готовый Сервис

Установочный скрипт должен оставаться небольшим. Основная настройка выполняется
в браузере:

1. Запустите bootstrap-скрипт на Linux-сервере.
2. Откройте временный адрес WebUI, который покажет скрипт.
3. Выберите язык интерфейса.
4. Выберите локальный доступ, интернет-доступ по домену или по IP.
5. Проверьте занятые порты и примите первый свободный предложенный порт либо
   укажите другой.
6. Создайте первую учетную запись администратора.
7. Создайте CS2-инстанс и выберите загрузку, импорт, копирование или перенос
   файлов сервера.
8. Укажите порт CS2, пароль RCON, GSLT, стартовую карту и желаемый пресет.
9. Откройте **Серверы**, нажмите **Установить / проверить** и подтвердите план SteamCMD.
10. Нажмите **Запустить** и проверьте команду запуска с замаскированными секретами.

Дополнительные изолированные инстансы создаются на экране серверов панели.

## Реализованные Возможности

- Развертывание только через Podman и отдельные файлы для каждого инстанса.
- Профиль установки на Bazzite без package layering базовой системы.
- Мастер настройки в браузере почти сразу после запуска bootstrap-скрипта.
- Установка, импорт, клонирование, обновление, проверка, запуск и остановка
  CS2-серверов.
- Проверка конфликтов портов с последовательным предложением начиная с
  `27015`.
- Предпросмотр аргументов запуска с маскировкой секретов.
- RCON-консоль, логи, пресеты конфигурации и пользовательские быстрые команды.
- Опциональные модули dashboard, Workshop-библиотеки, визуальной ротации карт
  и интеграций с плагинами.
- Русский и английский интерфейс.
- Резервные копии, обслуживание по расписанию, роли и журнал действий.
- Локальные парольные сессии с Argon2-хешами, strict cookies и ограничением
  частоты попыток входа.
- Полное удаление панели без удаления CS2-серверов по умолчанию.
- Опциональный локальный кэш изображений Workshop, checksum плагинов, проверка
  изменений HTTPS-источника и сторонние Python-модули со своими UI-вкладками.
- Управляемая установка latest MetaMod и CounterStrikeSharp `with-runtime`
  через официальные API релизов.
- Установка плагина из HTTPS-архива либо из локального ZIP-файла или
  распакованной папки внутри `/var/lib/cs2webui/imports`.
- Отслеживание примененной панелью команды смены карты и предупреждение, если
  A2S показывает другую стандартную карту.

## Принцип Модульности

Ядро предоставляет базовые операции. Модули улучшают интерфейс и добавляют
автоматизацию, но не являются обязательными.

Например, без модуля визуальной ротации пользователь по-прежнему может
редактировать конфигурацию вручную и отправлять RCON-команды. При установке
модуля появляются карточки карт, drag-and-drop, очередь и история изменений.

## Запуск Для Разработки

Рекомендуется Python `3.12+`.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
uvicorn cs2webui.app:create_app --factory --reload
```

После запуска откройте:

```text
http://127.0.0.1:8000/api/health
```

Запуск тестов:

```bash
pytest
```

## Основные API-Маршруты

```text
GET /api/health
GET /api/modules
GET /api/dashboard/summary
GET /api/setup/state
GET /api/setup/diagnostics
GET /api/instances
GET /api/instances/{id}/plugins
GET /api/rotation/{id}
```

Маршруты `/api/dashboard/summary` и `/api/rotation/{id}` добавляются
отключаемыми встроенными модулями. Их можно убрать независимо, сохранив
базовое управление инстансами, ручную настройку конфигурации и RCON-команды.

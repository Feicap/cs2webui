# Сторонние Модули

[English version](MODULES.md)

Модули CS2 WebUI добавляют опциональные API-маршруты и при необходимости
отдельный экран интерфейса. Модуль не должен импортировать или вызывать другой
опциональный модуль. Используйте состояние ядра или документированную
capability и корректно обрабатывайте отсутствие интеграции.

## Минимальный Пакет

Опубликуйте фабрику без аргументов через группу Python entry points
`cs2webui.modules`:

```toml
[project.entry-points."cs2webui.modules"]
simpleadmin = "cs2webui_simpleadmin:build_module"
```

Полный минимальный пример находится в [английской версии](MODULES.md).
Установите Python-пакет в окружение панели и перезапустите панель. Ядро
обнаружит его через entry point.

## Контракт Manifest

- `id`: постоянный уникальный идентификатор.
- `name`: понятное название.
- `version`: версия модуля.
- `description`: краткое назначение.
- `capabilities`: стабильные идентификаторы возможностей.
- `ui_path`: необязательная same-origin страница в sandboxed iframe.
- `navigation_label`: необязательное название вкладки для `ui_path`.

Параметры UI необязательны: модуль может добавлять только API. Iframe получает
обычную сессию панели для same-origin API-запросов, но модуль все равно обязан
проверять роль пользователя на каждом чувствительном маршруте.

## Изоляция Ошибок

Сторонний модуль является опциональным по контракту. Если загрузка entry point
или подключение router завершается исключением, ядро записывает ошибку в лог,
продолжает обслуживать панель и показывает модуль как недоступный через
`GET /api/modules`. Внутри собственных маршрутов модуль также должен по
возможности возвращать контролируемый статус деградации интеграции.
